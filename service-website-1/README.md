# Service Website

This project is a simple service website with separate pages for About, Services, Repair, and Contact. Each page follows a consistent design and uses the same color scheme and templates.

## Project Structure

```
service-website
├── pages
│   ├── about.html        # HTML structure for the About page
│   ├── services.html     # HTML structure for the Services page
│   ├── repair.html       # HTML structure for the Repair page
│   └── contact.html      # HTML structure for the Contact page
├── src
│   ├── components
│   │   ├── header.js     # Header component with navigation links
│   │   ├── footer.js     # Footer component with copyright information
│   │   └── page-template.js # Common layout for all pages
│   ├── styles
│   │   ├── colors.css    # Color scheme for the website
│   │   ├── global.css     # Global styles for all pages
│   │   └── pages.css      # Specific styles for individual pages
│   └── scripts
│       └── main.js       # JavaScript for interactive features
├── index.html            # Main landing page linking to individual pages
└── README.md             # Documentation for the project
```

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in a web browser to view the main landing page.
4. Navigate to the individual pages (About, Services, Repair, Contact) using the navigation links in the header.

## Overview

This website is designed to provide information about the services offered, including details on repairs and a contact form for inquiries. The consistent use of templates and styles ensures a cohesive user experience across all pages.
